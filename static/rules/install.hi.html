इस गेम को अपने फोन पर इंस्टॉल करें ताकि आप इसे होम स्क्रीन से तुरंत खोल सकें, बिना बार-बार वेबसाइट पते टाइप किए।

इंस्टॉल करने से क्या फायदा है?

  • होम स्क्रीन पर एक ऐप आइकन के रूप में गेम तक तेज़ पहुंच।
  • ब्राउज़र टैब खोजने की जरूरत नहीं।
  • पहली बार लोड करने के बाद गेम तेज़ी से खुलता है।

Android • Chrome / Edge / Samsung

  1. अपने फोन पर सुपर कार्ड्स वेबसाइट खोलें।
  2. ब्राउज़र के ऊपर-दाईं ओर तीन डॉट मेनू पर टैप करें।
  3. Install app या Add to Home screen चुनें।
  4. Install या Add पर टैप करें।
  5. अब आपका गेम होम स्क्रीन पर ऐप के रूप में दिखेगा।

iPhone • Safari

  1. अपने iPhone में Safari ब्राउज़र में सुपर कार्ड्स खोलें।
  2. नीचे की ओर स्थित Share बटन पर टैप करें।
  3. स्क्रॉल करके Add to Home Screen विकल्प खोजें।
  4. Add पर टैप करें और पुष्टि करें।
  5. गेम अब होम स्क्रीन पर ऐप की तरह तैयार होगा।

अगर इंस्टॉल का विकल्प न दिखे

  • पेज को रिफ़्रेश करें और फिर से आज़माएँ।
  • Android पर Chrome और iPhone पर Safari का उपयोग करें।
  • iPhone पर केवल Safari में यह ऑप्शन उपलब्ध होता है, अन्य ब्राउज़रों में नहीं।
  • यदि ऐप पहले से इंस्टॉल है, तो आपको Open दिखाई दे सकता है।

अधिक सहायता चाहिए?

यदि स्क्रीन बंद हो जाए, तो फिर से "Install on Android or iOS" बटन दबाएँ। यह गेम खासतौर पर मोबाइल पर आसान उपयोग के लिए तैयार किया गया है।
